# Transformer 与 GPT 的完整工作流程

这是一篇面向初学者的中文教程，从输入文本开始，系统讲解 GPT 如何完成 Token 预测、模型训练和自回归生成。

## 正文

[阅读《Transformer 与 GPT 的完整工作流程》](./Transformer与GPT的完整工作流程.md)

## 内容概览

- 文本如何经过 Tokenization、Embedding 和位置信息注入进入模型
- Q、K、V 与因果自注意力的计算过程
- 多头注意力、FFN、残差连接和层归一化的作用
- 隐藏状态如何转换为词表上的 Logits 与概率分布
- GPT 在训练阶段与推理阶段的工作方式
- 自回归生成、KV Cache、常见误区与完整数据流
- 章节总结和复习题

## 适合读者

- 希望理解 Transformer 和 GPT 基本原理的初学者
- 正在学习大语言模型、自然语言处理或深度学习的读者
- 想把分散概念串联成完整工作流程的开发者

文中包含公式、结构图和逐步解释。阅读前了解基本的向量、矩阵与概率概念会更容易，但不要求具备完整的机器学习背景。
