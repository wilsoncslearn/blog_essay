# 大白话吃透 Transformer，先别背公式，先把这条流水线看明白

事情是这样的。

很多人第一次学 Transformer，真正卡住的地方，其实不是 QKV，也不是多头注意力，也不是 FFN。

这些东西单独拿出来，好像都能听懂。

Q 是 Query，K 是 Key，V 是 Value。多头就是多个注意力头并行。FFN 是前馈网络。残差连接防止梯度爆炸或者消失。LayerNorm 让训练更稳定。

听起来都挺对。

但问题是，一旦把它们串起来，脑子里就开始冒烟了。

一个句子进来，怎么就变成了一堆向量？

一堆向量在模型里面转了几圈，怎么又变成了下一个字？

训练的时候到底在改什么？推理的时候到底又在干什么？

我自己刚学这块的时候，最难受的不是公式难，而是每个解释都像拆开的零件。你手里拿着螺丝、齿轮、弹簧，老师告诉你每个零件都很重要，但没人把整台机器重新装起来给你看。

所以这篇我想干一件很朴素的事。

不追求把所有细节讲到数学推导级别，也不假装一篇文章就能替代论文和源码。

我就是想用一条尽量像人话的链路，把 GPT 这种自回归 Transformer 从输入文字，到预测下一个 Token 的全过程，给你串一次。

你读完以后，不一定能手写一个 Transformer。

但至少再看到 QKV、多头、FFN、Logits、Softmax、训练、推理这些词的时候，脑子里不会是一团雾。

先抓住一根线。

GPT 这种模型，干的事情极其单纯。

给它一段上文，它预测下一个最合理的 Token。

先别急着往下钻细节，我们先把整条路压成一张图。

后面那些看起来吓人的名词，其实都能塞回这条流水线里。

就这一个动作。

你在 ChatGPT 里问一句话，它看起来在回答你，在推理，在写代码，在安慰你，在帮你分析人生。

但从底层任务看，它一直在做同一件事，读完前面的所有 Token，然后猜下一个 Token。猜出来以后，把这个 Token 接到后面，再猜下一个。就这么一格一格往前走。

这玩意听着有点傻。

但大模型最离谱的地方也在这里。

它不是先在脑子里生成一整篇文章，再慢慢吐出来。它就是在一次次局部预测里，逼出了一种看起来很像思考的能力。

大时代啊，朋友们。

那 Transformer 里面那么多模块，都在服务这件事。

注意力负责让每个 Token 去看别的 Token，知道上下文里谁跟我有关。

多头注意力负责从不同角度看，语法关系是一条线，指代关系是一条线，情绪和语义可能又是另一条线。

FFN 负责把每个 Token 已经收集到的信息，在自己内部再加工一下，揉一揉，压一压，提炼成更好用的语义表示。

残差连接和层归一化则更像工程上的护栏，让信息别在一层层计算里丢光，让训练别崩。

顺着这根线往下看，就清楚很多了。

我们从一句话开始。

假设你输入的是，小猫趴在垫子上，它睡着了。

模型拿到的不是汉字本身，而是一串 Token。Token 可以理解成模型词表里的编号，有时候对应一个字，有时候对应一个词，有时候对应一个词的一部分。

这些编号本身没啥语义。

就像身份证号不能直接告诉你这个人长什么样，Token 编号也不能直接告诉模型这个词是什么意思。

所以第一步，是把 Token 编号变成向量。

这个向量可以先粗暴理解成一个很长的坐标。小猫有自己的坐标，垫子有自己的坐标，睡着也有自己的坐标。坐标越接近，某些语义关系可能越近。

当然真实情况比这个复杂得多，但你先这么理解，不丢人。

愚钝如我，当年就是靠这种很土的图像感把它吞下去的。

现在每个 Token 都变成了向量，问题来了。

小猫这个 Token 不能只知道自己是小猫，它还得知道它在这句话里的位置和关系。

它是主语吗？它和垫子是什么关系？后面的它指的是小猫，还是垫子？

这时候，自注意力就上场了。

自注意力最容易被 QKV 这三个字母吓住，其实你先别怕。

Q 可以理解成，我现在想找什么信息。

K 可以理解成，我身上挂着什么标签，方便别人来找我。

V 可以理解成，如果你真的找到了我，我能提供什么内容。

还是那句话，小猫趴在垫子上，它睡着了。

当模型处理它这个 Token 的时候，Q 大概会带着一种搜索意图，我想知道自己指向谁。

前面的每个 Token 都有自己的 K。小猫的 K 里有动物、主体、前文名词这些味道。垫子的 K 里有物体、地点、被趴着的对象这些味道。

它的 Q 去跟这些 K 一个个做匹配。

匹配高的，权重就高。

于是模型会更关注小猫，而不是垫子。

然后真正被拿过来融合的，是 V。

你可以把 K 想成图书馆书脊上的标签，把 V 想成书里面真正的内容。Q 拿着检索需求去扫标签，扫到相关的书，再把书里的内容拿出来。

这个比喻不完美，但够用了。

自注意力干的事情，就是让每个 Token 都有机会去全句子里查资料，再把跟自己有关的信息吸回来。

这就是横向交互。

你会发现，真正决定去哪里找的是 Q 和 K，真正被搬回来的信息则在 V 里面。

不是一个词孤零零地理解自己，而是每个词都带着上下文重新理解自己。

看到这里，你可能会问，那一个注意力头不就够了吗？

真不够。

一句话里的关系太多了。

它指向谁，是一种关系。

主语和谓语怎么配，是一种关系。

前后情绪怎么连，是一种关系。

长距离依赖又是一种关系。

如果只给一个头，它就像一个人同时盯着会议纪要、聊天记录、法律条款和饭局气氛，迟早顾不过来。

多头注意力的思路就很简单。

那就多派几个人看。

有的头专门敏感指代关系，有的头更容易抓语法结构，有的头盯局部词组，有的头负责长距离呼应。

注意，我这里说专门，其实是为了方便理解。真实训练里没有人手动规定第 3 个头负责指代，第 7 个头负责情绪。它们是在大量数据里自己学出来的分工。

这块挺神奇的。

模型没有被老师拿着教鞭说，你这个头以后负责找主语。

它就是在一次次预测下一个 Token 的压力里，慢慢长出了这种分工。

有点像一个创业小团队，刚开始大家什么都干，混乱得要死。项目做久了以后，有人自然开始管产品，有人自然开始管工程，有人自然开始管客户。没人正式任命，但分工就长出来了。

多头注意力算完以后，每个头都会吐出一份自己的理解。

这些理解先被拼起来，也就是 Concat。

拼起来还不够。

因为拼接只是把几份材料堆在桌上，还没有决定哪些更重要，哪些可以合并，哪些要压低权重。

所以后面还会接一个输出投影矩阵 $W_O$。

它像一个总编辑，把几个记者交上来的材料重新编排。这个头看到的指代关系要保留，那个头看到的局部搭配也有用，另一个头可能这次贡献不大，就少听一点。

这一步以后，一个 Token 的向量里，已经混进了来自上下文的大量信息。

但这还没完。

因为注意力主要解决的是，信息从哪里来，谁该看谁。

它更像搬运和汇聚。

真正让单个 Token 在内部发生更复杂变化的，是 FFN。

很多人学 Transformer，最容易把 FFN 当成一个不起眼的尾巴。

不是哥们，这块很重要。

注意力把素材拿回来了，但素材还只是素材。你开会听了一圈意见，不等于你已经形成了判断。你还得回到自己的脑子里，把这些信息消化掉。

FFN 做的就是这个独自复盘的过程。

它不让 Token 之间继续聊天。

每个 Token 都单独进去，单独出来。

但是在这个单独处理的过程中，向量会先被升维，进入一个更宽的空间，再经过激活函数筛一下，最后压回原来的维度。

你可以把它想成，一个人把刚刚收集到的所有信息摊开，在草稿纸上疯狂画线，删掉没用的，突出重要的，再整理成一句更凝练的话。

这里有个很关键的点。

如果全程都只是线性变换，模型能表达的东西会很有限。

激活函数引入了非线性，模型才有机会表达更复杂的关系。

听着很数学对吧。

我还是用大白话讲。

如果没有非线性，很多变化就像只允许你拉伸、旋转、平移一张纸。纸还是那张纸，花样有限。

有了非线性，就像允许你折纸、剪纸、叠出新的形状。模型能学到的关系一下子丰富很多。

所以注意力和 FFN 的分工，可以先记成一句话。

注意力让 Token 出门打听消息。

FFN 让 Token 回屋消化消息。

一个横向社交，一个纵向修炼。

然后就是残差连接和层归一化。

这两个东西不太像故事主角，但没有它们，整套系统很容易训练不动。

残差连接可以理解成，别把原始信息扔了。

每一层做完计算以后，不是完全用新结果覆盖旧结果，而是把旧信息也接回来。这样层数堆得很深的时候，底层信息还有路可以往上传。

层归一化则像每一段计算之后，把数值状态稍微整理一下，别让某些维度大到飞起，某些维度小到没影。

这两个放在一起，Transformer Block 才能一层一层堆上去。

一个 Block 里，大概就是这么个节奏。

多头注意力让 Token 们互相看一眼，拿上下文。

残差和归一化稳一下。

FFN 让每个 Token 自己加工。

再残差和归一化稳一下。

然后进入下一层。

这是一张为了理解而简化的图。不同 GPT 和 Transformer 变体，会把 LayerNorm 放在子层前面或者后面，也就是常说的 Pre-Norm 和 Post-Norm，但注意力、FFN、残差这几个角色不会凭空消失。

一层又一层。

浅层可能更像在处理局部搭配、语法关系、短距离依赖。深层会慢慢抽象出更复杂的语义、逻辑、意图和风格。

当然这不是说每一层都有一个写死的岗位说明书。

模型内部没有贴着标签说，我是语法层，我是逻辑层。

这是我们从外部观察时比较容易理解的一种说法。

说实话，我们对大模型内部到底怎么组织这些能力，今天也还没完全搞明白。

很多时候，我们是在看一个巨大的黑箱，在输入和输出之间，努力猜它中间发生了什么。

这也是这件事迷人的地方。

当所有 Transformer Block 跑完以后，我们会得到一个最终的语义矩阵。

你可以叫它 Final_X。

这个矩阵里，每一行对应一个位置上的 Token。每一行都是这个 Token 经过多层上下文融合和内部加工后的结果。

它不再是最开始那个孤零零的词向量了。

它已经带着前文关系、句法位置、语义联想、上下文暗示，甚至某种风格倾向。

但问题又来了。

向量还是向量。

模型怎么把它变成文字？

这就是很多教程突然断片的地方。

前面还在讲语义空间，后面突然开始说 Logits 和 Softmax，中间像被剪掉了一段。

其实连接点很朴素。

模型会拿最后一个位置的语义向量，去和词表里所有候选 Token 做匹配打分。

词表里每个 Token 也有自己的向量。

你的最终向量像一个问题，词表里的每个候选 Token 像一个答案。模型把这个问题和所有答案都对一遍，匹配高的分数高，匹配低的分数低。

这一堆原始分数，就是 Logits。

Logits 还不是概率。

它只是一个排行榜的原始打分。

再经过 Softmax，这些分数会被压成一个总和为 1 的概率分布。

这时候模型就知道，下一个 Token 是某个词的概率更高，另一个词的概率更低。

如果永远选概率最高的那个，输出会更稳定，但也容易无聊，甚至卡在重复里。

如果加入 Top-k、Top-p、temperature 这些采样策略，模型就会在合理范围内有一点随机性。

这就是为什么你问同一个问题，它有时候会给出不完全一样的回答。

不是它突然有了情绪。

是生成策略让它在多个合理候选里做了不同选择。

这块需要注意一下。

这里最好把推理和训练直接摆在一张表里看。

这两条路线最大的分界线，不是有没有 Softmax，而是权重到底改不改。

推理的时候，模型参数是不更新的。

你跟 ChatGPT 聊天，它不是每说一句就现场学习一次，把 $W_Q$、$W_K$、$W_V$、FFN 这些权重改掉。

它只是拿固定的参数，基于当前上下文，一步步算出下一个 Token。

生成一个 Token，接回输入序列，再算下一个。

像打字机。

但这个打字机每敲一下之前，都要把前文重新理解一遍。

训练阶段就完全是另一回事了。

训练的时候，有标准答案。

模型看到一段文本的前面部分，预测下一个 Token，然后和真实下一个 Token 对比。

猜得离谱，损失就大。

猜得接近，损失就小。

这个损失会通过反向传播，一层层往回传，去调整嵌入层、QKV、输出投影、FFN 这些参数。

训练的目标不是让模型背一句话，而是让它在海量文本里不断形成一种能力。

看到某种上下文，知道后面更可能接什么。

更准确一点说，是让内部语义向量和正确 Token 的匹配分数越来越高，让错误 Token 的分数相对下降。

你想想看，这个过程其实挺残酷的。

模型一开始什么都不懂，只是在巨大的语料里一遍遍被问，后面该是什么。

错了就改。

再错再改。

改到最后，它对语言结构、事实关联、代码模式、推理模板、人类情绪，都形成了某种压缩后的统计理解。

它没有像人一样读过人生。

但它读过太多人留下来的语言痕迹。

这也是为什么大模型有时候特别聪明，有时候又特别荒诞。

它能在语言的纹理里抓到惊人的模式，也可能在没有真实世界锚点的时候一本正经地胡说八道。

所以回到最开始那条线。

一段文字进来，被切成 Token。

Token 变成向量。

向量进入一层层 Transformer Block。

注意力负责横向看上下文，多头负责从不同视角看，FFN 负责单个 Token 内部加工，残差和归一化负责让深层网络稳定地跑下去。

最后得到的语义向量，拿去跟词表里所有候选 Token 打分，得到 Logits，再经过 Softmax 和采样策略，吐出下一个 Token。

然后把这个 Token 拼回去。

继续。

继续。

继续。

直到一段回答出现在你面前。

这就是 GPT 类自回归 Transformer 最核心的闭环。

坦率的讲，理解这套东西以后，再看大模型会有一种很奇妙的感觉。

它没那么玄学了。

但也没有因此变得无聊。

恰恰相反，它更迷人了。

因为你会意识到，我们今天看到的很多智能表现，居然是从一个极其简单的训练目标里冒出来的。

预测下一个 Token。

听起来像小学生填空。

结果一路堆到了写代码、做题、画图、规划任务、陪人聊天。

你敢信？？？

尼玛。

这不就是复杂系统最让人着迷的地方吗？

一条简单规则，足够大的规模，足够多的数据，足够长的训练，最后长出一种我们还在努力命名的东西。

有人会说，这不就是统计吗？

我非常理解这种说法。

如果你站在工程和数学的角度，它确实是在做概率建模，确实是在拟合分布，确实没有一个小人在里面认真思考。

但屏幕前的你也可以回想一下，当一个模型把你的混乱想法整理成一段清楚的话，当它在代码里找到你半天没看出来的 bug，当它把一个抽象概念讲到你突然懂了，那一刻你感受到的东西，很难只用概率两个字轻轻放下。

不是说概率不对。

而是说，概率堆到这个尺度以后，它开始在人的体验里长出新的名字。

智能也好，涌现也好，幻觉也好，工具也好。

我们还在给它取名字。

而理解 Transformer，至少能让我们少一点迷信，也少一点傲慢。

它不是魔法。

它也不是玩具。

它是一台把语言里的关系压缩进向量，再从向量里一点点吐回语言的巨大机器。

你给它上文，它预测下一个 Token。

然后下一个。

再下一个。

一格一格，时间就这么流出来了。

我一直觉得，学大模型最爽的时刻，不是背下某个公式，而是突然把一条链路接上。

哦，原来 QKV 在这里。

哦，原来多头是这么分工的。

哦，原来 FFN 不是摆设。

哦，原来 Logits 到文字中间差的是一次词表匹配和概率采样。

那种雾散开的感觉，真的挺赤鸡的。
